Matching settings
Detects when an outflow (debit) from an account and an inflow (credit) of the same amount back to the same account form a pair — a sign that the bank returned the money. Matching by order number (ref) is reliable; if it is missing, a fallback is used: the same amount within the given number of days (less reliable, marked differently).
